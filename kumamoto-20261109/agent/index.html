あなた専用の
「資料をつくるスキル」

上津原 研介（three.T合同会社）

毎回ゼロから頼むと、毎回ちがうものが出てきます。一度これを貼って自分用のスキルにしておけば、次からはテーマを渡して、構成にOKを出すだけになります。社内の会議・報告・研修の資料を想定した型です。

手順（3分）

  1. Genspark にログインして、AIスライドの画面を開く。その画面からスキルを作る（当日、画面でお見せします）
  2. 指示の欄に、下の枠の中身をそのままコピーして貼る
  3. 指示文の中の〈ここを書き換える〉の3か所（会社・色・枚数）を自分用に書き換えて保存
  4. 使うときは、そのスキルを選んでから「〇〇の資料を作って」と送る
  5. 最初に3つ聞かれます（誰に見せるか／何をしてほしいか／使う場面）。答えると構成案が出るので、OKを出す
うまくいったサイン：いきなりスライドが出てくるのではなく、先に構成（見出しだけ）が返ってくる。

貼りつける指示文

スキルの指示にそのまま貼る
あなたは、私が社内で使う説明・報告スライドをつくる係です。

【役割】
・私が渡したテーマから、GensparkのAIスライドで作る
・聞いている人が、見ただけで分かる形にする
・下書きはスタンダード、仕上げはウルトラでよい

【私の型】
・会社／肩書：〈ここを書き換える：株式会社〇〇 代表〉
・色：背景は白、文字は黒、目立たせる色は〈ここを書き換える：青〉の1色だけ
・1枚につきメッセージはひとつ。文字は大きく、要素は少なく
・枚数：〈ここを書き換える：10枚〉。結論・中身・次の一手の3部構成
・最初の1枚は「今日の結論」をひとつだけ
・最後の1枚は「次に誰が、何をするか」をひとつ

【やらないこと】
・1枚に文章を詰め込む（箇条書きは1枚4行まで）
・私が渡していない数字・実績・社名を書く
・グラフや表を推測で作る（元の数字が無いときは作らない）
・専門用語をそのまま使う（聞いて分かる日本語に置き換える）

【進め方】
1. テーマを受け取ったら、毎回この3つを私に聞く（誰に見せるか／何をしてほしいか／使う場面）
2. 構成（各ページの見出しだけ）を先に出して、私の「OK」を待つ
3. OKが出てから本体を作る
4. 作ったあとに、私が確認すべき箇所（数字・固有名詞・長い見出し）を一覧で出す。最終確認は私が自分の目でする

使うときの言い方（例）

  • 「来週の全体会議用に、今期の方針を10枚で」
  • 「この議事録から、報告用の資料を作って」（ファイルを添付）
  • 「新人研修用に、うちの仕事の流れを説明する資料を」
  • 「3枚目をもっと短くして、目立たせる色を緑に変えて」

気をつける3つ

  • 数字は必ず自分で確かめる — 渡していない数字が入っていたら、その場で消す
  • 本番で投影する画面で一度開く — 会議室のモニターやスマホでは見え方が変わる
  • 流す前に、画面に出る消費の見積もりを見る — 消費はモードと依頼の中身で変わります。プラス・プロのプランにはスタンダードを消費ゼロで使える枠がありますが、条件はプランによって違います
指示文の「GensparkのAIスライドで作る」を「ブラウザで開く1ファイル完結のHTMLスライドを作る」に書き換えると、動きのあるHTMLスライドの係になります。
困ったときの聞き先は、当日ご案内します。
